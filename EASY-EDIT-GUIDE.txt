GLOSSÉ — EASY EDIT GUIDE
==========================

This version is made so you do NOT have to redesign the website.

1. PRODUCT PHOTOS
-----------------
Open:
    assets/products/

Replace these six files with your own photos, keeping the SAME filenames:
    lipstick.jpg
    gloss.jpg
    foundation.jpg
    blush.jpg
    mascara.jpg
    highlighter.jpg

Your new image should ideally be a JPG or PNG with the same filename.
If you use a different filename, edit products.js accordingly.

2. PRODUCT NAMES / PRICES / REVIEWS
-----------------------------------
Open:
    products.js

You will see each product like this:

{
  name: "Velvet Matte Lipstick",
  category: "LIPS",
  price: "2,850",
  reviews: "124",
  image: "assets/products/lipstick.jpg"
}

Change only the values inside the quotes.

Example:
    name: "My New Lipstick",
    category: "LIPS",
    price: "3,200",
    reviews: "0",
    image: "assets/products/my-lipstick.jpg"

3. OPEN THE WEBSITE
-------------------
Double-click:
    index.html

It opens in Chrome/Edge/Safari.

4. IMPORTANT
-------------
Keep index.html, products.js and the assets folder together.
Do not move products.js somewhere else.

5. TO ADD MORE PRODUCTS
-----------------------
Copy one product block in products.js, give it a new name/price,
and put the new photo inside assets/products/.

6. REAL BUSINESS DETAILS
------------------------
Before selling for real, replace the demo WhatsApp checkout,
delivery details, policies, social links and payment setup with
your real business information.

The visual design itself is already prepared to match the GLOSSÉ
reference design.
